# 근거 검증과 서비스 범위

목표: NVDA/AMD Peer 리서치를 실제 API 또는 명시된 스냅샷으로 실행하고, 근거 검사를 통과한 제안만 보고서에 게시한다. LLM의 환각 0%나 투자 판단의 정확도는 보장하지 않는다.

## 게시 계약

- AI는 도구 선택·추가 자료 수집·선정 제안을 담당한다. 자유 생성 요약·이유·기준 설명은 공식 결과에 게시하지 않는다. 해당 필드는 코드가 데이터로 구성한다.
- 알 수 없는 출처, 다른 기업 출처, 기준일 이후 자료, SEC 외 URL, 비교 검사 생략, 자료 부족, 정책 기준 미달은 선정을 보류한다. 차단 사유를 기록한다.
- 제품·시장 태그는 큐레이션 입력이며 원문 검증을 마친 사실로 표시하지 않는다. 공시 발췌에서의 기업명 일치는 관계의 의미를 입증하지 않는다.
- 비율·점수는 코드에서 계산한다. 규칙 점수·민감도는 정확도나 사실일 확률이 아니다.
- 실행 결과는 로컬 디스크에 원본과 해시를 저장한다. 승인/반려는 별도 기록한다. 키 미설정·수집 실패를 데모 성공으로 바꾸지 않는다.

## 검증과 종료 조건

`npm test`, `npm run typecheck`, `npm run build` 및 HTTP로 분석→저장→재열람→승인 흐름을 확인한다. 평가 사례는 `evals/golden-cases.md`에 둔다. 위험 사례의 잘못된 선정 게시를 0건으로 요구한다. 이는 고정 회귀 사례에 대한 결과이며 일반적인 환각률 측정이 아니다.

실제 LLM 호출은 ANTHROPIC_API_KEY와 SEC_USER_AGENT 설정 후 별도 실행해야 한다. 현재 키가 없어 라이브 검증은 미완료다. 로컬 단일 사용자 서비스 범위이며 공용 배포용 인증·다중 사용자 저장소·24시간 공시 감시는 포함하지 않는다.
