# 검토 기준

Pass: 게시한 숫자가 공시 원값 또는 재현 가능한 코드 계산이고 출처·기간·기업을 추적할 수 있다. 자유 생성 문장은 게시하지 않는다. 검증 실패는 보류로 남는다. 원본 실행과 승인 이력을 다시 읽을 수 있다.

Warn: 큐레이션 태그, 회계기간 차이, 스냅샷 시차, 사업 관계의 의미 해석, 규칙 가중치 선택은 사람이 검토한다. 검사 통과는 경제적 적합성의 정답 인증이 아니다.

Fail: 허위 숫자/출처가 선정 근거로 게시됨, 검토 중단을 완료로 표시, 원문 일치만으로 관계의 진실성을 인증, 변조되거나 미검증인 실행 승인, 실제 API 미실행을 실제 실행으로 표시.

변경마다 자동 회귀 평가를 수행한다. 라이브 키 설정 후 실제 실행을 저장해 별도 사람 검토를 수행한다. 현재 자동 테스트만으로 전체 LLM 오류율을 추정하지 않는다.
