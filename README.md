# 근거 기반 Peer Group 리서치 서비스

NVIDIA와 AMD를 대상으로 공시를 수집하고 비교기업을 제안하는 로컬 단일 사용자 서비스입니다. AI가 도구 호출과 선정 제안을 담당하고, 코드가 수치·출처·게시 규칙을 검사해 설명을 구성합니다. 담당자는 저장된 원본 실행을 검토해 승인하거나 반려합니다.

**환각 0%를 보장하지 않습니다.** LLM 자유 문장이 공식 설명에 게시되는 경로를 막고, 검사에 실패한 제안은 보류합니다. 검사 통과는 투자 판단이나 경제적 비교 적합성의 정답 인증이 아닙니다.

## 실행

```bash
npm install
npm run dev                     # http://localhost:3000
# 또는
npm run build
npm start
```

- 데모: 키 없이 저장된 SEC 스냅샷 + 규칙 정책으로 실행합니다. 실제 LLM 실행으로 표시하지 않습니다.
- 실제: `.env.example`을 참고해 `.env.local`에 `ANTHROPIC_API_KEY`, 연락처를 포함한 `SEC_USER_AGENT`를 설정하고 서버를 다시 시작합니다. 키는 서버에서만 사용합니다. 실패해도 데모로 전환하지 않습니다.
- 선택 설정: `ANTHROPIC_MODEL`(기본 `claude-opus-5-5`), `ANTHROPIC_EFFORT`(`low/medium/high`), `PEER_RUNS_DIR`(기본 `.local/runs`).

## 사용 흐름

1. 대상·기준일·모드를 선택해 분석을 시작합니다.
2. 지도·근거·비교표에서 선정 제안과 공시 원값을 확인합니다. `S#`를 누르면 수집 출처와 원문 발췌로 이동합니다.
3. **신뢰성·기록**에서 후보별 검사 결과, 보류 사유, 저장된 원본 실행을 확인합니다.
4. 완료된 원래 실행이 게시 검사를 통과한 경우 승인할 수 있습니다. 직접 Peer 구성을 변경한 상태에서는 승인 버튼이 비활성화됩니다. 승인·반려는 매매 실행을 뜻하지 않습니다.
5. 보고서와 CSV를 내려받습니다. 직접 바꾼 Peer는 원래 제안과 구분하며, 검사에 실패한 후보는 추가·내보내기할 수 없습니다.
6. 서버를 재시작해도 기록을 다시 불러올 수 있습니다. 원본 payload의 SHA256이 맞지 않으면 조회·승인을 거부합니다.

## 신뢰성 계약

| 구분 | 동작 | 남는 검토 |
|---|---|---|
| 재무 원값 | SEC XBRL, 기업 CIK·접수번호·공시일·기간·유한 수치 확인 | 공시 자체 오류·항목 정의 |
| 계산 지표 | 코드 계산, CSV에 입력 출처와 산식 기록 | 회계기간 차이·비교 목적 |
| AI 제안 | 도구 선택·추가 수집·선정 제안 | 탐색 누락·선정 편향 |
| 설명 | AI 자유 문장/assessment/관계 분류 대신 데이터 템플릿·규칙 사용 | 규칙·큐레이션의 적합성 |
| 출처 | 등록 ID, 대상/후보 기업, SEC URL·CIK, 기준일 검사 | 출처 존재가 결론의 정답을 뜻하지 않음 |
| 선정 | 두 기업 재무·사업 근거, 비교 검사, 자료 충분성, 점수 기준·개수 한도 | 최종 Peer 선택은 사람 판단 |
| 불합격·중단 | `hold` 저장, 미검토가 남으면 부분/실패 표시 | 보완 후 재실행 필요 |
| 기록 | 실행 원본·도구 호출 제안·검사 결과 저장, 승인/반려 별도 기록 | 로컬 해시는 전자서명·사용자 인증 아님 |

숫자 탐지기는 퍼센트·달러 B·배수 표현을 보조 검사합니다. 문장 전체의 진실성을 증명하지 않습니다. 탐지하지 못한 자유 문장도 공식 설명에는 게시하지 않습니다. 원래 모델 제안은 감사 목적의 도구 호출 인자에 남을 수 있습니다.

정책·평가: [게시 계약](docs/10_eval-plan.md), [고정 사례](evals/golden-cases.md), [판정 기준](evals/rubric.md), [실패 유형](evals/failure-modes.md).

## 추가 분석

- **강건성:** 가중치·기준선을 바꾼 선정 빈도입니다. 정확도나 신뢰 확률이 아닙니다.
- **시점 비교:** 기준일 이전 재무·공시로 규칙 정책을 실행합니다. 제품·시장 태그는 현재 큐레이션이므로 전체 분석의 미래 정보 누수가 없다고 주장하지 않습니다.
- **지식그래프:** 원문 인용이 있는 관계 후보입니다. 인용문 일치가 관계의 의미·방향을 입증하지 않으며, 모든 추출 관계는 `review_required`입니다. 일부 수집/추출 실패는 `partial`로 표시합니다.

## 코드와 API

| 경로 | 역할 |
|---|---|
| `lib/agent.ts`, `lib/llm.ts` | 도구 루프·선정 제안·게시 검사 |
| `lib/financials.ts`, `lib/peer.ts` | 기간 정규화·계산·비교 가능성·참고 점수 |
| `lib/publication.ts`, `lib/report.ts` | 게시 경계·출처·산식 |
| `lib/runs.ts` | 원본 저장·무결성 확인·승인 |
| `POST /api/analyze` | NDJSON 진행 상태와 저장된 결과 |
| `GET /api/runs`, `GET /api/runs/[id]` | 최근 기록·원본 조회 |
| `PATCH /api/runs/[id]` | `{decision: approved 또는 rejected, note, digest}`로 원본 검토 |
| `POST /api/graph`, `POST /api/timeline` | 관계 후보·시점 비교 |

## 데이터와 한계

- us-gaap, USD, 연간 양식, 350~380일 기간을 사용합니다. 중복은 기준일 이전 최신 공시, 같은 날에는 수정 공시를 우선합니다. 누락을 추정하지 않습니다.
- 대상 2개·고정 후보군 10개입니다. IFRS만 있는 기업은 재무 비교에서 차단합니다. 제품/시장 태그는 사람이 정리한 입력이며 세그먼트 매출은 미수집입니다.
- 원문은 키워드 발췌여서 섹션 경계를 정확히 잡지 못할 수 있습니다. 스냅샷은 기업별 최근 4개 연간보고서 발췌를 포함합니다.
- 실제 조회 캐시는 5분 후 갱신합니다. 24시간 자동 공시 감시·알림은 아직 없습니다.
- 저장은 로컬 디스크이며 승인 기록은 마지막 판단을 보관합니다. 다중 사용자 인증·변경 불가 감사 원장·공용 배포 환경은 포함하지 않습니다. 공용 배포에는 인증·영속 저장소·운영 한도 설정이 필요합니다.
- 실제 모드 한도: 도구 60회, 판단 20회, 재시도 2회, 280초. 데모: 도구 70회, 판단 12회, 60초.
- SEC 이용 시 연락처를 담은 User-Agent와 공정접근 정책을 지킵니다. 스냅샷 갱신: `npm run snapshot`.

## 검증

```bash
npm test
npm run typecheck
npm run build
```

회귀 검사는 위조/타기업/미래 출처, 미수집 수치·부호 반전, 자유 문장 유출, 비교 검사 누락, 조기 종료, 내보내기 우회, 관계 의미 오인, 결과 변조, 승인 제한을 다룹니다. 고정 사례 통과율은 일반적인 LLM 환각률이 아닙니다.

현재 환경에 키가 없어 **실제 Claude 호출의 품질·비용·소요 시간은 미검증**입니다. 실제 모드는 [공식 strict tool-use 문서](https://platform.claude.com/docs/en/agents-and-tools/tool-use/strict-tool-use)와 설치 SDK를 확인해 정식 Messages API로 구성했습니다. 라이브 검증은 키 설정 후 실행 원본을 저장해 별도로 검토해야 합니다.
