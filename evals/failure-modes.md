# 주요 실패와 대응

| 실패 | 대응 | 남는 한계 |
|---|---|---|
| 출처 ID 세탁 | 기업·종류·시점·SEC URL 검사, 불합격 보류 | 공시 자체의 오류 |
| 수치 생성·부호 반전 | 계산은 코드, AI 수치 불일치 차단 | XBRL 정의의 경제적 차이 |
| 그럴듯한 허위 설명 | 자유 문장 게시 금지, 데이터 템플릿 | 큐레이션 태그 품질 |
| 프롬프트 주입 | 도구 입력 검증, 후보 제한, 게시 검사 | 자료 수집의 누락/선택 편향 |
| 인용과 관계의 불일치 | 관계는 검토 필요로 표시 | 사람의 의미 검토 필요 |
| API/시간 한도·조기 종료 | 실패/부분 상태, 미검토 표시 | 실제 API 검증은 키 필요 |
| 저장 후 변조 | 원본 SHA256 확인 후 조회/승인 | 로컬 관리자에 대한 인증 아님 |
| 오래된 캐시 | 유효기간 후 재수집 | 완전한 실시간 감시 아님 |
